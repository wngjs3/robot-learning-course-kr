# Robot Learning 한국어 🤖🇰🇷

- **💬 한국어 자막** — 전체 스크립트의 자연스러운 한국어 번역 (영어 원문 병기 가능)
- **🖼 한국어 슬라이드** — 강의 슬라이드를 AI로 한국어 번역·재생성, 영상과 나란히 동기화
- **✨ 강의 요약** — 전체 요약, 핵심 포인트, 핵심 용어 정리
